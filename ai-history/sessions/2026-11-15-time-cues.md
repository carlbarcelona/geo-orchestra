## Asked

Add a music cue, in both Geophony and Musical, that marks a passing day or month, or a checkpoint set by the user, so listeners can follow the passing of time while the sound plays.
- Preset mode uses one uniform cue.
- Advanced mode lets the user configure it.

The lead's choices:
- Preset marks every year (Numerical) and every month's 1st (Visual feed), plus checkpoints.
- A checkpoint is the same knock, louder and doubled.
- The teammate's `sound/element-mute-mode-panel` branch is left to its author.

## Done

- `src/sound/timeCues.ts` (`cue-v1`, pure): period boundaries for the monthly and seasonal timelines, `timeCueEvents`, the fixed `PRESET_TIME_CUES`, cue sounds, and the spacing hint.
- Checkpoints replace the ordinary cue on their step.
- The engine gets a "Time cues" layer with woodblock, bell, click, drum and chime voices, and plays in both modes. The Musical-only `year` tick is no longer sounded; the year marker stays in the events for the marker lane. `MAPPING.version` is unchanged because the rain events did not change.
- Store and actions:
  - `checkpoints` and `timeCues` per workspace.
  - `effectiveTimeCues`: Preset mode always uses the fixed cue.
  - `toggleCheckpoint` (key **C**), remove, rename, jump.
  - `setTimeCues`, `auditionCue`.
  - Events refresh without stopping playback.
  - Both are saved in project files as optional fields.
- UI:
  - ⚑ Checkpoint button and checkpoint chips in the music chart.
  - Flags in the piano roll, dotted lines in the graphs.
  - "New year ·" and "Checkpoint “…” ·" caption prefixes.
  - A Knock line in the Preset guide with previews.
  - Advanced "Time cues & checkpoints" controls in both sound panels.
  - A "Time cues" level slider.
  - A legend section "When are we?".
  - Narration speaks checkpoint labels.
- `npm run check`: 86 tests (12 new). `npm run build` passes. Clicked through in Chrome (see docs/verification.md).

## Tried and abandoned

- The plan said to rename the existing geophony `cue` field (thunder/wind) to avoid a clash. Instead the new field is named `timeCue`, which leaves the rain mapping's output untouched.
- The browser test first sent synthetic key events to `window`, and the shortcut handler crashed on `closest`. That was a test artifact, but the handler now treats non-element targets as page-level keys.
