The interface has two modes, switched at the right of the Numerical | Visual feed bar. **Preset** is what a first-time visitor sees. **Advanced** is the original interface with every control.

**Why:** the team lead wants first-time and non-technical users (students, judges, the public) to get a one-click start and plain-language guidance. Technical users still need every configuration control.

**How to apply:**
- A new control goes in Advanced by default. It also goes in Preset only if a non-technical user needs it.
- Never remove a control from Advanced to simplify Preset.
- Honesty labels (reconstructed linkage, seasonal average, image-derived, missing ≠ zero) must appear in **both** modes.
- Switching mode must never change data or playback.
