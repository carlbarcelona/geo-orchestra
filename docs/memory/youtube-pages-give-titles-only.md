name: youtube-pages-give-titles-only
description: "Fetching a YouTube link with the agent tools returns only the video title, not the description or the video"
type: reference
date: 2026-11-15
---

When a teammate shares YouTube links as references, an agent's web fetch gets only the page title. The page is rendered client-side, so the description, channel and transcript don't come back, and the video can't be watched.

**Why:** on 2026-11-15 the four NASA sonification references for the whole-frame sweep came back as titles only. The design had to rest on the lead's description.

**How to apply:** ask the person sharing the video for the points that matter (what the line does, what maps to pitch and loudness), or for a text source such as the NASA page for the same sonification. Don't claim to have watched a video.
